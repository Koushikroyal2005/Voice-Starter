# First local voice conversation

## Current selection: Groq Whisper → Groq LLM → Groq Orpheus

The ignored backend `.env` now selects:

```dotenv
STT_PROVIDER=groq
STT_MODEL=whisper-large-v3-turbo
STT_ALLOW_BATCH=true
STT_REQUIRE_INTERIM=false
TURN_DETECTION=vad
STT_LANGUAGE=en
LLM_PROVIDER=openai_compatible
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_MODEL=openai/gpt-oss-20b
TTS_PROVIDER=groq
TTS_MODEL=canopylabs/orpheus-v1-english
TTS_VOICE=troy
TTS_LANGUAGE=en
```

`LLM_API_KEY` retains your existing Groq key. In the ignored file,
`GROQ_API_KEY=${LLM_API_KEY}` appears **after** that key definition so python-dotenv
can resolve it. Alternatively set both to the same real key privately. This does
not change the existing LLM adapter or enable NVIDIA fallback.

Whisper is batch-only, returns final transcripts (no partials), and uses the existing
LiveKit STT StreamAdapter plus Silero VAD. Do not enable interim requirements or
STT endpointing for this profile. Gemini's separate streaming profile is below.

Orpheus accepts complete text requests, not streaming text. LiveKit sentence
adaptation feeds its native ChunkedStream. The adapter caps individual requests
at 200 characters, consumes WAV response bytes incrementally, and uses native
AudioEmitter segments to decode each independent WAV. It adds no custom audio
conversion or playback buffering. Cancellation closes the response context;
remote generation/billing cancellation is not guaranteed. English voices are
autumn, diana, hannah, austin, daniel and troy. The separate Arabic model is not
registered here; no Telugu Orpheus synthesis is promised.

STT reuses the installed `openai.STT` against `/audio/transcriptions`. TTS needs
a small native LiveKit adapter: the installed `openai.TTS` sends `stream_format`,
which Groq explicitly rejected with HTTP 400, `invalid_request_error`,
`unknown field stream_format in request body`. The new adapter sends only
model/input/voice/response_format to `/audio/speech`, requests WAV, sanitizes
provider errors and preserves bounded retries/timeouts. Existing providers remain
registered and their capability checks have not been weakened. No dependencies added.

Sources: [Groq speech-to-text](https://console.groq.com/docs/speech-to-text),
[Orpheus models/voices/limits](https://console.groq.com/docs/text-to-speech/orpheus).

## Installed SDK contract

Agents and Google plugin 1.8.12 are already pinned; no dependencies added.
Constructors were checked against installed source and `inspect.signature`:

- `google.beta.GeminiSTT(api_key=..., model=..., language=..., vertexai=False)`:
  native streaming recognition with real interim/final events; streaming-only,
  not `recognize()` batch mode. Chat models such as `gemini-2.5-flash` cannot replace
  its Live-capable transcription model. Keep existing Silero VAD endpointing.
- `google.beta.GeminiTTS(api_key=..., model=..., voice_name=..., vertexai=False)`:
  native chunked audio at 24 kHz mono. Its `streaming=False` capability refers to
  **text input**, not fake/buffered browser audio. AgentSession uses LiveKit's
  sentence StreamAdapter. Local cancellation/barge-in stays owned by LiveKit;
  cancelling locally does not guarantee remote billing stops.
- Groq remains `openai.LLM(api_key=..., base_url=..., model=...)`.

The current [STT guide](https://docs.livekit.io/agents/models/stt/gemini/) contains
different inference/plugin examples; the installed beta streaming implementation
is authoritative for this pin. Do not substitute Google Cloud `google.STT` or
`google.TTS`: those constructors use Cloud credentials, not this AI Studio key.
See also the [Gemini TTS guide](https://docs.livekit.io/agents/models/tts/gemini/).
Multilingual coverage is model-dependent; no Telugu/code-switching claim is made.
`TTS_LANGUAGE` does not select a Gemini speech locale; Gemini derives pronunciation
from input text and voice. Voice names are validated against the installed plugin.

## Manual browser acceptance test (after speech access is resolved)

1. Start exactly one worker; confirm registration against localhost, not Cloud.
2. Open http://localhost:3000, choose voice connection and allow microphone access.
3. Confirm the worker receives a job and the UI shows an agent participant.
4. Say “What is two plus two?” Watch genuine partial then final user transcripts.
5. Confirm Groq response text and audible Gemini response through speakers.
6. While it speaks, say “Stop. What time is it?” Verify obsolete playback stops
   and the deterministic time tool completes. Do not confuse muting with interruption.
7. End session; confirm browser disconnects and the worker finishes that job.
8. Reconnect and repeat once. On a provider failure, retain the stage/status code,
   but do not share keys, full JWTs, private transcripts or raw request logs.

The development token endpoint remains development-only. This is not a public
production deployment and uses hosted model APIs, not offline inference.
